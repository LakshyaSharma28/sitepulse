# SitePulse — Website Health Checker

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

**SitePulse** is a lightweight CLI tool that checks website availability, response times, HTTPS certificate expiry, and security headers — all from your terminal.

> ⚠️ **For authorized targets only.** Always obtain permission before scanning websites you do not own.

## Features

- ✅ HTTP availability and status code
- ⏱️ Response time in milliseconds
- 🔒 HTTPS certificate expiry and days remaining
- 🛡️ Security header audit (HSTS, CSP, X-Frame-Options, etc.)
